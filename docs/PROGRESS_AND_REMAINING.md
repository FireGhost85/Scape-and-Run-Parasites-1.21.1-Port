# SRP port: progress and what remains (as of 2026-10-08, after commit e060b14)

Port of **Scape and Run: Parasites 1.10.9** (Minecraft 1.12.2 Forge, modid `srparasites`) to **Minecraft 1.21.1, NeoForge 21.1.256, Java 21, Mojang mappings**. Goal: a faithful port with the same content, numbers, names, config keys and behaviour as the original jar. The jar wins over any document.

Read these in order: this file, `docs/HANDOFF.md` (rules, flags), `docs/PORTING_GUIDE.md` (conventions, 1.12 to 1.21 cheat sheet), `docs/PORTING_PLAN.md`, `docs/JAR_INVENTORY.md`, `PORTING_NOTES.md` (every deviation), `porting/notes/effects.md`, `porting/notes/blocks.md`.

## 2. Build state

`gradlew compileJava` fails with about 226 errors, all caused by classes that do not exist yet (entities, items, worldgen, biomes, `ParasiteEventWorld`, `SRPAttributes`, `SRPWorldData`, `BeckonBlockInfestation`, `ItemModule`). The finished areas have no errors of their own. To see all errors, use an init script that adds `-Xmaxerrs 10000 -XDshould-stop.ifError=FLOW` to `JavaCompile` (`gradlew compileJava -I script.gradle`). `porting/notes/blocks.md` lists which missing symbol each finished class needs.

## 4. Rules and decisions that stay

- Keep the `srparasites` namespace, registry names, config keys and defaults. Do not add new parasite types. New vanilla content only as configurable `[ADD]` additions.
- Do not invent mechanics. If the jar is ambiguous, flag it and ask. Every deviation goes into `PORTING_NOTES.md` as `[CHG]`, `[FLAG]` or `[ADD]`.
- Beckon Stage V is ported dormant (not registered, not spawned). Dimension id `270` stays an unmapped legacy id.
- Do not stub missing dependencies silently: port them, or write a documented placeholder with a `[CHG]` note.
- Compile with `gradlew compileJava` after each area. The user runs `runClient` and sends the log. Do not commit unless asked.

## 5. Open flags that need the user

- Several vanilla `SoundEvents` SRG ids have no name in `porting/spec/srg_names.csv` (gothshroom, fog nullifier sounds, guessed for now). The MCP 1.12.2 mappings (`mcp_stable-39-1.12.zip`, about 3 MB, maven.minecraftforge.net) would settle them; downloading needs the user's OK.
- Parasite fog uses `air()`; check in game that fog-only chunk sections render. Details in `docs/HANDOFF.md` and `PORTING_NOTES.md`.
- Original bugs deliberately kept (see `PORTING_NOTES.md`): infested remain survival check, gore neighbour check, canister creative-only count, infuser shift-click.

## 6. Working with the original jar

- Jar: `H:\Minecraft\Mods 1.12.2\SRParasites-1.10.9.jar` (SRG-named).
- Decompile with CFR 0.152 (Maven Central, `org/benf/cfr/0.152`; ask the user before downloading) into a folder outside the project, e.g. `java -jar cfr-0.152.jar <jar> --outputdir <out> --silent true`. Then run `porting/tools/annotate_names.py` to add MCP names as comments. Names missing from `porting/spec/srg_names.csv` must be decoded from usage.
- Extract the jar with `unzip` into another scratch folder for assets (`assets/srparasites`) and data.
- Existing tools: `porting/tools/gen_meta_map.py`, `gen_blocks_spec.py`, `gen_config.py`, `annotate_names.py`.
- Tooling quirk: bash heredocs break on apostrophes and backslashes; use the Write/Edit tools for files.

**Important gameplay note (not a bug):** the special abilities, sprinting and water leaps of the parasites are gated by the *Generation* of the dimension (0-5, `/srpgeneration`), not by the evolution phase. With the default config specials (`generationSpecialM*`) start at generation 4, sprinting at 2, water leap at 3, faster attacks at 3-5. A fresh world is generation 0, so parasites look slow and without their special attacks even at phase 6. Test with `/srpgeneration setgeneration 4` (or 5). The generation grows with time (`generationTime1..`).

**Fixed this session:** Beckon stages I/III/IV were bright green (glow textures had RGB in transparent pixels; cleaned), enderman parasites ignored all damage, parasite food theft took any item, deprecated `EventBusSubscriber.Bus` arguments removed.

**Open bugs:** Yelloweye (Emana) acid box (`EntityNade`, damage = father attack damage 3.5, applied by `selfExplode`) reportedly does no damage: not diagnosed; enderman parasites reportedly not despawning/hard hitting: not diagnosed; structure NBT walls use the old wall format; `damage` entity not summonable; a few textures missing in the original jar.
